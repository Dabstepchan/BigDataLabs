# Лабораторная работа №4
# Выполнил студент группы МОАм-251 Козырев А.Д.

ML-пайплайн рекомендательной системы от прототипа до production: выбор модели и Model Registry в MLflow, Feature Store на Feast, инференс-сервис на FastAPI с canary, shadow и откатом, мониторинг дрейфа, сравнение пакетного и онлайн-обучения, обработка холодного старта. Отдельно - прогноз температуры сенсора NAB с автоотключением. Пошаговая реализация и результаты - в ноутбуке `Lab_BigData_4.ipynb`.

**Вариант 5:** E-commerce Clickstream, файл `2019-Oct.csv` ([Kaggle](https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store)); уникальное требование - обработка холодных стартеров. Часть 8 - ряд NAB `ambient_temperature_system_failure.csv`.

**Бизнес-сценарий:** 2. Рекомендательная система (latency < 100 мс, рост CTR на 10%, согласованность фич offline/online).

**Оформление:** вариант B, Jupyter Notebook.

## Запуск

Ноутбук рассчитан на запуск с нуля («Выполнить всё») в Google Colab или в любом окружении с Python 3.10+:

```bash
pip install -r requirements.txt
jupyter nbconvert --to notebook --execute Lab_BigData_4.ipynb   # или открыть и выполнить все ячейки
```

Первая ячейка ставит недостающие пакеты, данные скачиваются сами (`kagglehub` и GitHub NAB). Ноутбук поднимает MLflow Tracking Server на порту 5000 и инференс-сервис на порту 8000; промежуточные данные и база MLflow лежат в `work/`. Тесты: `pytest -q tests`.

## Краткие выводы

- **Модель:** LightGBM, AUC 0,7795 (эвристика без обучения 0,7008), p99 предсказания одной строки 4,8 мс; случайный лес даёт то же качество при p99 46 мс.
- **Feature Store:** все три проверки согласованности пройдены (Feast = прототип, online = прямой расчёт, online = offline).
- **Реестр моделей:** версия 3 стала `champion`; версия 4 (только фичи запроса, AUC 0,5764) отклонена валидацией.
- **Сервис:** p50 12,3 мс, p99 22,7 мс последовательно (требование < 100 мс); при 8 параллельных потоках p50 118,6 мс, предел одного процесса около 70 запросов/с. Canary 5%, shadow (корреляция оценок 0,908) и автоматический откат битой модели проверены.
- **Мониторинг:** дрейфа на 8-9 октября нет (`drift_score` 0, максимальный PSI 0,079); искусственный сдвиг цен ×1,5 ловится (PSI 9,81). Retrain сработал по плановому сроку.
- **Пакетное и онлайн-обучение:** пакетное точнее (AUC через 24 ч 0,7871 против 0,7601), онлайн дешевле по CPU и задержке; выбрано пакетное с ежедневным обновлением.
- **Холодный старт:** AUC ранжировщика почти не изменился, а запасной список по категории товара поднял HitRate@10 холодных пользователей с 0,0806 до 0,2733 (+0,193).
- **Прогноз сенсора NAB:** прямая стратегия даёт лучшие квантили, MASE ниже 1. Решающий слой поймал аварию 1 в момент выхода за порог, верхнее правило пропустило аварию 2 (температура падала), нижнее поймало её ценой 14 ложных тревог из 19.
- **Ограничения:** рост CTR на 10% офлайн не проверяется, измерены AUC и HitRate@10; использованы 5% пользователей, 9 дней данных и один тестовый день.
